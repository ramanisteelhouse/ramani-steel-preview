# Ramani Steel House — static preview

Generated output of the Ramani Steel House website, published for review on
GitHub Pages. The source repository is private.

This is a **static preview**, not the live site:

- The enquiry forms are replaced by phone and email links. A static host cannot
  run the server action that captures a lead.
- Legacy redirects and security headers do not apply.
- Every page is `noindex, nofollow` and `robots.txt` disallows all crawlers, so
  this copy cannot compete with the real domain in search results.
